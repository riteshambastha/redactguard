# redactguard-plugin-sdk

Base classes (`AbstractDetector`, `DetectionResult`) and the
`register_detector` API for building third-party detector plugins for
[RedactGuard](https://github.com/riteshambastha/redactguard). See
`examples/example_tattoo_detector_plugin/` for a design sketch.
